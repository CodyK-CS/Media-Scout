# Media Scout
Media Scout is a local HTML-based application with an easy-to-navigate interface for finding photos, GIFs, and videos. It searches websites you have selected based on the media type and source you choose. For example, selecting Photos and Pixabay will search Pixabay for photos that are relevant to your query.
